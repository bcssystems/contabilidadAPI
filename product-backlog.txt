PRODUCT BACKLOG - OMI CONTABILIDAD
==================================

Ultima actualizacion: 2026-10-04
Estado general: En implementacion

OBJETIVO DE ESTA FASE
---------------------
Implementar la administracion laboral y el checador: todos los usuarios seran empleados,
con sueldo semanal, horarios fijos, breaks configurables, marcaje obligatorio de entrada
y salida con selfie y ubicacion, revision administrativa, justificaciones e integracion
con nomina.

DECISIONES CONFIRMADAS
----------------------
[x] Todos los usuarios, sin importar su rol, son empleados.
[x] Administradores y usuarios deben marcar entrada y salida.
[x] El sueldo es semanal.
[x] Los breaks no cuentan como tiempo laboral y no requieren selfie.
[x] No se permiten horarios que crucen medianoche.
[x] No hay cambios de horario por dia en esta primera version; el horario semanal es fijo.
[x] La selfie es obligatoria para entrada y salida.
[x] La ubicacion se valida contra puntos geograficos autorizados.
[x] El radio inicial de cada punto geografico es de 100 metros.
[x] Fuera del radio se permite el marcaje, pero queda como incidencia pendiente.
[x] Si se supera el umbral de entrada o salida, se descuenta una hora completa.
[x] Las justificaciones las aprueban administradores.
[x] Las deducciones de asistencia requieren aprobacion antes de entrar a nomina.
[x] La nomina es semanal.
[x] Se usara Google Maps para seleccionar puntos geograficos.
[ ] Definir si se descuenta una hora por cada evento o por cada bloque completo en retardos mayores.
[ ] Definir politica de retencion de selfies y coordenadas.

CONFIGURACION GOOGLE MAPS
-------------------------
La clave debe configurarse como variable de entorno o parametro de despliegue.
No se debe escribir una clave real en este archivo ni en el repositorio.

Variable propuesta:
GOOGLE_MAPS_API_KEY

APIs necesarias:
- Maps JavaScript API
- Places API, solamente si se habilita busqueda de direcciones

Checklist de la clave:
[ ] Crear proyecto en Google Cloud Console.
[ ] Habilitar facturacion.
[ ] Habilitar Maps JavaScript API.
[ ] Habilitar Places API si aplica.
[ ] Crear API key.
[ ] Restringir por HTTP referrers del frontend.
[ ] Restringir la clave solamente a las APIs necesarias.
[ ] Configurar la clave en el entorno local y produccion.
[ ] Verificar limites y alertas de facturacion.
